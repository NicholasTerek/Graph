The recording uses the production-built UI and real local SDK/API/FalkorDB requests, not canned UI responses.

The seven captioned stages show the live recommendation; captured source/rule/native-path evidence; an isolated supplier delay changing the recommendation; a recorded deterministic tool investigation; an evidence-bound GitHub proposal; selective promotion's explicit review gate; and return to unchanged live state. This is synthetic data and deterministic orchestration. It does not validate a configured model, authenticated provider accounts, a real external action or human judgment. No action is executed and no issue is sent. The caption explicitly labels that scope. The slow/reading pauses apply only to recording mode; normal tests retain their ordinary speed.
